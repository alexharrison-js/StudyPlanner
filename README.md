# StudyPlanner

This is a free-tier focussed system for personal study planning including new information intake for current/evolving topics (like AI research or programming), curriculum adjustment and planning for offine-study (languages, music, art), and spatial repetition. Connect your compute and llm account details for agents or plug in a local model.

If you feel inclined to contribute, great! Open a PR that describes your change, and why it's necessary or helpful, and I'll be happy to take contributions.

Please refer to the principles of development as described in the Architectural Decision Records (ADRs) in the `/docs/adr` directory when designing and implementing any feature or addition. Please feel free to use or add development-prompts in the `/docs/development-prompts` directory that would be helpful.

Note that AI and LLMs have and will continue to be relied on for implementation and expansion of this project, but not without detailed human review of every change. That being said, as this expands, if I or anyone contribute unnecessarily verbose AI generated code, that will detract from the goal of being an easyily understandable, easily self-hosted and adaptable open-source software project. So let's not do that.
